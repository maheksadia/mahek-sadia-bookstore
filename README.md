# Mahek Sadia — Official Digital Bookstore

Vercel-ready React/Vite bookstore with a private-looking admin dashboard, PDF ebook upload, built-in browser reader, INR default pricing and international currency display.

## Demo admin password
`mahek2026`

## Important
The current admin upload stores books in the browser's local storage. This is suitable for a prototype/demo. For a real public store where an upload persists across devices and customers, connect Supabase Storage + authentication and server-side payment verification.

Build: `npm run build`
Output: `dist`
